# TV Proxy

Прокси-клиент для Android TV: пускает выбранные приложения через HTTP или SOCKS5 прокси (с логином/паролем), остальные — напрямую.

## Возможности
- **HTTP (CONNECT)** и **SOCKS5**, авторизация логин/пароль (Basic / RFC 1929).
- **Выбор приложений**: «только выбранные через прокси» или «все, кроме выбранных».
- **DNS через прокси** (DNS-over-TCP к указанному серверу, по умолчанию 1.1.1.1) — без утечек DNS; можно переключить на прямой UDP, если прокси не пускает на порт 53.
- **UDP через SOCKS5** (UDP ASSOCIATE) — игры, звонки, QUIC. Включается галочкой; если сервер не поддерживает UDP, ошибка видна на экране, а TCP продолжает работать.
- Кнопка **«Проверить прокси»** — показывает внешний IP через прокси, время ответа и работает ли UDP.
- Ошибки прокси (неверный пароль, отказ в подключении) видны на главном экране.
- **Автозапуск** при включении ТВ.
- Управление пультом (D-pad), тёмная тема, баннер для лаунчера Android TV.

## Как устроено
`VpnService` создаёт TUN-интерфейс только для выбранных приложений (`addAllowedApplication` / `addDisallowedApplication`).
Пакеты разбирает собственный упрощённый TCP-стек на Kotlin (`net/TcpSession.kt`), каждое соединение открывается через прокси (`net/ProxyConnector.kt`).
DNS (UDP:53) перехватывается в `net/DnsForwarder.kt`. Прочий UDP в режиме SOCKS5 идёт через `net/UdpRelay.kt` (UDP ASSOCIATE), в режиме HTTP отбрасывается — приложения переходят на TCP.
Нативных библиотек нет.

## Сборка и установка
```
gradle assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
```
Готовый APK: `TvProxy.apk` (подписан debug-ключом).

## Ограничения
- Через HTTP-прокси UDP не передаётся (протокол этого не умеет) — только через SOCKS5, и только если сервер поддерживает UDP ASSOCIATE.
- Фрагментированные SOCKS5 UDP-датаграммы не поддерживаются (на практике серверы их не используют).
- IPv6-соединения проксируются, если прокси умеет подключаться к IPv6-адресам.
